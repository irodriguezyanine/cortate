<product_requirements>
CÓRTATE.CL is a web (and future mobile) platform connecting clients with barbers for booking services, ratings, and an Uber-like quick cut mode. Barbers can create profiles, manage bookings, view ratings, and upload work.

**Client User Flow:**
1.  **Registration/Login:** Full name, email, password, profile photo (optional), geolocation/address, T&Cs.
2.  **Home:** Personalized welcome with Buscar Barbería (Map) and Corte Rápido (Uber Mode) buttons.
3.  **Search:** Filters (location, price, services, availability, style, rating), results on map/list.
4.  **Barber Profile:** Photos, bio, services/prices, agenda, reviews (with photos), gallery, likes/comments.
5.  **Booking:** Select service, day/time, confirmation.
6.  **Quick Cut:** Client enters type, max budget, location; system notifies available barbers; real-time tracking (optional).
7.  **Post-cut:** Star rating, comment, upload photos (optional).
8.  **My Bookings:** Past/future cuts, status, cancel/reschedule.

**Barber User Flow:**
1.  **Registration:** Full name, email, password, phone, address/GPS, profile/cover photos, business info (name, description, services, availability), T&Cs.
2.  **Dashboard:** View bookings, edit profile/services, gallery, ratings, stats, toggle Quick Cut Availability.
3.  **Quick Cut Requests:** View incoming requests (type, budget, location), accept/reject.
4.  **Respond Reviews:** Reply to comments, report offensive content.
5.  **Upload Photos:** Upload work photos (receive likes/comments, mark as Featured).

**Security:** JWT authentication, password recovery, automatic penalties.
**API Keys:** Google Maps API Key, Google Geocoding API Key.
**Database:** MongoDB Atlas URL.
**Focus:** Web version first, responsive design for future app.

**Implemented So Far (as per AI's last claim before current task):**
*   Differentiated client/barber registration and interfaces.
*   Client and barber data saving in MongoDB (though persistence issues persist).
*   Automatic geocoding for barber addresses, appearing on map.
*   Functional Quick Cut system with Uber-like states, timer, budget, distance, and home/local options.
*   Full booking system (select service, date/time, notes).
*   Barber panel showing bookings and quick-cut requests with timers.
*   Google Maps integration showing barber locations.
*   Basic UI with Tailwind CSS and Shadcn UI components.
</product_requirements>
